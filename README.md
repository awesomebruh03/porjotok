# পর্যটক (Porjotok) — ডিজিটাল প্রকাশনা ও সাময়িকী প্রোটোটাইপ

**পর্যটক (Porjotok)** হলো একটি মার্জিত ও প্রামাণ্য বাংলা ডিজিটাল ভ্রমণ, ভূগোল, সংস্কৃতি, ঐতিহ্য ও পরিবেশ বিষয়ক সাময়িকীর ইন্টারঅ্যাকটিভ ফ্রন্টএন্ড প্রোটোটাইপ।

মূল ডিজাইন রেফারেন্স (`for prototype/` ডিরেক্টরি) পুঙ্খানুপুঙ্খভাবে বিশ্লেষণ করে প্রতিষ্ঠিত একটি স্বয়ংসম্পূর্ণ ভিজ্যুয়াল ডিজাইন সিস্টেমের ওপর ভিত্তি করে এই একক-পৃষ্ঠা অ্যাপ্লিকেশনটি (SPA) নির্মিত হয়েছে।

---

## 🎨 ডিজাইন সিস্টেম ও ভিজ্যুয়াল আইডেন্টিটি

প্রোটোটাইপের রঙ, টাইপোগ্রাফি এবং লেআউট উপাদানসমূহ রেফারেন্স আর্টবোর্ডের সাথে নিখুঁতভাবে সঙ্গতিপূর্ণ:

- **কালার প্যালেট (Color Tokens):**
  - **ওয়ার্ম আইভরি / ক্রিম গ্রাউন্ড (`#F4F1EA`):** প্রচ্ছদ নিবন্ধ ও সর্বশেষ প্রতিবেদনের জন্য মার্জিত অফ-হোয়াইট ব্যাকগ্রাউন্ড।
  - **ডিপ ওয়াটার টিল (`#0F2B34`, `#0B2027`):** সংখ্যা সংগ্রহ, রিফ্লেকশন ব্যান্ড, সাবস্ক্রিপশন প্যানেল ও ফুটারের জন্য গভীর জলের মতো নিবিড় নীল-সবুজ আভা।
  - **উজ্জ্বল হলুদ অ্যাকসেন্ট (`#FDD835` / `#FFDF00`):** সিগনেচার ইমেজ ফ্রেম, কর্নার ব্র্যাকেট, আন্ডারলাইন রুল ও হাইলাইটার।
  - **ক্রিমসন রেড সেকেন্ডারি অ্যাকসেন্ট (`#A31D1D` / `#C41E24`):** প্রচ্ছদ প্রতিবেদন ব্যাজ, স্কয়ার বুলেট (`■`) এবং প্রধান কল-টু-অ্যাকশন বোতাম।
  - **ডার্ক চারকোল (`#1E2328`, `#0F2B34`):** প্রামাণ্য টাইপোগ্রাফি ও পাঠযোগ্য বডি টেক্সট।

- **টাইপোগ্রাফি:**
  - **হেডলাইন ও শিরোনাম:** গুগল ফন্টের ক্লাসিক এডিটোরিয়াল বাংলা সেরিফ ফন্ট **`Noto Serif Bengali`**।
  - **বডি টেক্সট ও ইউআই উপাদান:** পরিষ্কার ও আধুনিক বাংলা সান্স-সেরিফ **`Hind Siliguri`** ও **`Anek Bangla`**।
  - **ড্রপ ক্যাপ ও উদ্ধৃতি:** দীর্ঘ নিবন্ধ পাঠের জন্য ঐতিহ্যবাহী লাল ড্রপ ক্যাপ (`.first-letter-drop`) এবং হলুদ বর্ডারযুক্ত মার্জিনাল কোট (`blockquote`)।

- **ফ্রেমিং ও ভিজ্যুয়াল ট্রিটমেন্ট:**
  - প্রতিটি আলোকচিত্রে চারপাশের সুনির্দিষ্ট হলুদ ফ্রেম (`yellow-framed-image`) ও ইনার হোয়াইট ম্যাট।
  - ম্যাগাজিন প্রচ্ছদের নিচে মেঝেতে প্রতিফলনের স্নিগ্ধ ভার্চুয়াল এফেক্ট (`cover-reflection`)।
  - হিরো সেকশনের চার কোণে হলুদ এল-আকৃতির ফ্রেম ব্র্যাকেট (`hero-corner-tl`, `hero-corner-tr`, ইত্যাদি)।

## 🧭 বাস্তবায়িত পাতাসমূহ (Implemented Pages)

| **B. সংখ্যা সংগ্রহ** | `#/publications` | মুদ্রিত ও ডিজিটাল ম্যাগাজিন সংখ্যার তালিকা, বর্ষভিত্তিক ফিল্টার (২০২৬, ২০২৫, বিশেষ সংখ্যা), স্পেসিফিকেশন ও একক কপি অর্ডার। |

| **D. সকল প্রতিবেদন** | `#/articles` | ক্যাটাগরি ফিল্টার পিল (ভ্রমণ, প্রকৃতি, সংস্কৃতি, ঐতিহ্য, ইতিহাস, জীবনযাপন), লাইভ সার্চ ফিল্টার, লিড ফিচার্ড কার্ড এবং লোড-মোর পেজিনেশন। |

| **F. বিষয়ভিত্তিক বিভাগ** | `#/categories` & `#/categories/:cat` | ৬টি মূল বিভাগের ওভারভিউ ও প্রতিটি বিভাগের বিস্তারিত নিবন্ধের কিউরেটেড তালিকা। |
| **G. আমাদের সম্পর্কে** | `#/about` | পত্রিকার দর্শন ও অভিযাত্রা, ৪টি মূল সম্পাদনা নীতি, সম্পাদকীয় পর্ষদের পরিচিতি। |
| **H. যোগাযোগ ও দপ্তর** | `#/contact` | প্রধান কার্যালয় ও বরেন্দ্র ব্যুরোর তথ্য, লেখা পাঠানোর নিয়মাবলী, রিয়েল-টাইম ক্লায়েন্ট ভ্যালিডেশনযুক্ত ইন্টারঅ্যাকটিভ যোগাযোগ ফরম। |

## ⚡ ইন্টারঅ্যাকশন ও ফাংশনালিটি

1. **ক্লায়েন্ট-সাইড রাউটিং:** কোনো ব্যাকএন্ড সার্ভার কনফিগারেশন ছাড়াই যেকোনো পাতায় সরাসরি যাওয়া যায় এবং ব্রাউজারের ব্যাক/ফরোয়ার্ড হিস্ট্রি সঠিকভাবে কাজ করে।
2. **সার্চ সিস্টেম:** লাইভ বাংলা কি-ওয়ার্ড দিয়ে প্রতিবেদন ও ম্যাগাজিনের শিরোনাম, সারাংশ, অঞ্চল ও লেখক ফিল্টার করা যায়।
3. **সাবস্ক্রিপশন ও ক্রয় মডাল:** হেডার ও সেকশন ৬ থেকে বার্ষিক সদস্যপদ (৳ ১২০০), একক মুদ্রিত কপি (৳ ২২০) বা ডিজিটাল সংস্করণ (৳ ১০০) অর্ডারের সিমুলেশন।
4. **নিউজলেটার সাবস্ক্রিপশন:** ফুটারে ইমেইল ভ্যালিডেশনসহ ইনস্ট্যান্ট টোস্ট ফিডব্যাক।
5. **শেয়ার ও বুকমার্ক:** ব্রাউজারের নেটিভ শেয়ার সাপোর্ট, ক্লিপবোর্ডে কপি ও `localStorage`-এ সংরক্ষিত তালিকার পারসিস্টেন্স।
6. **মোবাইল ড্রয়ার মেনু:** ছোট স্ক্রিনে মসৃণ রেসপন্সিভ ড্রয়ার নেভিগেশন।

## 🚀 লোকালি রান করার নিয়মাবলী

### পূর্বশর্ত
- Node.js (v18+) এবং npm

### ১. ডিপেন্ডেন্সি ইনস্টল (যদি এখনও না করা থাকে)
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু করা
```bash
npm run dev
```
ব্রাউজারে খুলুন: `http://localhost:5173/`

### ৩. প্রডাকশন বিল্ড ও প্রিভিউ
```bash
npm run build
npm run preview
```
বিল্ড ফাইলসমূহ `dist/` ফোল্ডারে সংরক্ষিত হবে।
